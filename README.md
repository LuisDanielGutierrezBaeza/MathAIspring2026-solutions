# Mathematics of AI - Spring 2026

Este repositorio contiene las soluciones, códigos y actividades desarrolladas para el curso **Mathematics of AI** (MathAIspring2026UTSA) y ha sido desarrollado con fines estrictamente académicos para el curso *Mathematics of AI*. Las asignaciones, planteamientos teóricos, conjuntos de datos de prueba y guías conceptuales provienen del material oficial del curso diseñado por el **Dr. Eduardo Dueñez**, disponible en su sitio web público: [MathAIspring2026UTSA](https://eduenez.github.io/MathAIspring2026UTSA/). 
El propósito de este proyecto es estudiar y documentar los fundamentos matemáticos del Deep Learning como parte de una asignación académica.
Las soluciones matemáticas y las implementaciones en Python presentadas aquí son utilizando el material de clase citado como base teórica fundamental.
